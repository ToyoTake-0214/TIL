### 継承について

改めて便利だったので、継承について、親クラスが持つ機能を子クラスが引き継ぐ仕組み。

Rubyでは `<` を使って表す。

```
class Dog < Animal
end
```

この場合、`Dog` は `Animal` を継承しているため、`Animal` に定義されたメソッドを `Dog` でも使用できる。

Railsでも、

```
class User < ApplicationRecord
end
```

のように使われており、`User` は `ApplicationRecord` の機能を引き継いでいる。

継承を使うことで、共通する処理を親クラスにまとめ、子クラス側で再利用できる。
