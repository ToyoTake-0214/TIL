## システムスペックの基本

システムスペックは、人がブラウザでやる操作をコードにして確かめるテストである。
書き方はモデルスペックと同じく describe / context / it / expect を使う。

流れは「準備 → 実行 → 確認」の3つ。
準備では create でデータを作る。画面がDBからデータを読むため、build ではなく create を使うことが多い。
実行では visit で画面を開き、fill_in で入力し、click_button などで操作する。
確認では expect(page) を使い、have_content で表示を、have_current_path で移動先を確かめる。

ドライバ（どのブラウザで動かすか）には rack_test と Chrome がある。
rack_test はHTMLを読むだけのブラウザのふりで、速く準備もいらないが、JavaScriptは動かない。
Chrome は本物のブラウザで、JavaScriptも動くが、遅く準備も必要になる。
HTMLだけで確かめられることは rack_test、JavaScriptの動きを確かめたいときは Chrome を使う。
ドライバは rails_helper.rb でまとめて設定でき、テストの書き方はドライバに関係なく同じである。
