## Reactの再レンダリング最適化（memo / useCallback / useMemo）

Reactでは、不要な再レンダリングや再計算を防ぐために、メモ化という仕組みを使う。

メモ化とは、前回の結果を保存して、同じ条件なら再利用すること。

### ① memo：コンポーネントのメモ化

```
const Greeting = memo(({ name }) => {
  return <p>こんにちは、{name}さん</p>;
});
```

- コンポーネントを`memo()`で囲む。
- 親コンポーネントが再レンダリングされても、受け取るprops（name）が前回と同じなら、基本的に再レンダリングをスキップする。
- 不要な再レンダリングを減らせる。

### ② useCallback：関数のメモ化

```
const handleClick = useCallback(() => {
  setCount(prevCount => prevCount + 1);
}, []);
```

- 関数を`useCallback()`で囲む。
- 依存配列`[]`の値が変わらない限り、同じ関数を再利用する。
- 子コンポーネントに関数をpropsとして渡すときなどに便利。

※ `setCount(prevCount => prevCount + 1)`は、現在のstateを元に更新する書き方であり、メモ化そのものではない。

### ③ useMemo：計算結果のメモ化

```
const result = useMemo(() => {
  return a + b;
}, [a, b]);
```

- 計算結果やオブジェクトなどの値をメモ化する。
- `a`と`b`が変わらない限り、前回の計算結果を再利用する。
- 重い計算を毎回実行することを防げる。
