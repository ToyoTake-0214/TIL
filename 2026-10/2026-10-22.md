### ① useState とジェネリック(復習)

- `useState<TaskFormData>()` の `<>` はジェネリックで、管理するデータの型を指定する
- `<>` は型の指定、`()` は初期値を渡すためのもの
- `setFormData` を使って state を更新する

### ② Props と分割代入(復習)

- `TaskForm({ formData, onChange, onSubmit }: Props)` は親から渡された Props を分割代入で取り出している
- `: Props` は受け取るデータや関数の型を指定している
- Props ではデータだけでなく関数も渡せる

### ③ フォームの入力処理

- `name` は入力欄を識別する名前
- `value` は初期値ではなく、現在の値を表示する
- `onChange` は入力内容が変更されたときに呼ばれる
- 入力内容が変わるたびに state が更新され、画面に反映される

### ④ イベントオブジェクトと分割代入

- `e` はイベント情報を受け取る変数で、名前は自由に変更できる
- `target` はイベントが発生した要素を指すプロパティ
- `e.target.name` で入力欄の名前、`e.target.value` で現在の値を取得できる
- `const { name, value } = e.target` は分割代入で、順番を入れ替えても同じ値を取り出せる

### ⑤ スプレッド構文(復習)

- `...prev` はスプレッド構文で、更新前のオブジェクトの中身を展開する
- 変更していない項目の値を残しながら、必要な項目だけ上書きできる
- 分割代入は値を取り出す書き方、スプレッド構文は値を展開する書き方

### ⑥ useNavigate

- `useNavigate()` は React Router のフック
- `navigate("/tasks")` でタスク一覧ページに移動できる
- タスク作成後の画面遷移などに利用する

### ⑦ 日時の取得

- `new Date()` で現在の日時を取得する
- `.toISOString()` で日時を ISO 形式の文字列に変換する
- タスクの作成日時などを記録するために使用する

### ⑧ モックデータと Promise

- `mockTasks.push(newTask)` で配列に新しいタスクを追加する
- `resolve(newTask)` で Promise を成功として完了させ、作成したタスクを結果として渡す
- `setTimeout` の `500` は500ミリ秒（0.5秒）
- `push()` で追加されるのはメモリ上の配列であり、モックデータのファイル自体は変更されない
