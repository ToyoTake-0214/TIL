探すとapp/decorators/article_decorator.rbが引っかかったので

```
  1 module ArticleDecorator
  2   def eye_catch_url(version = :origin)
  3     if !eye_catch.attached? || !eye_catch.blob.persisted?
  4       return '/images/eye_catch.jpg'
  5     end
  6
  7     command = case version
  8               when :thumb
  9                 { resize: '640x480' }
 10               when :lg
 11                 { resize: '1024x768' }
 12               when :ogp
 13                 { resize: '120x630' }
 14               else
 15                 false
 16               end
 17
 18     command ? eye_catch.variant(command).processed : eye_catch
 19   end
 20 end
```

なのでこのファイルを利用すると

- 影響範囲が広いのは「 `ArticleDecorator` というファイル」そのものではなく、「 その中に定義されている `eye_catch_url` という 1つのメソッド 
- `ArticleDecorator` は `Article` のインスタンスに `include` される( ActiveDecorator の仕組みで、 `Article` オブジェクトに対して自動的にこのモジュールのメソッドが呼べるようになる )だけなので、 モジュール自体に「状態」や「副作用」を持つわけではない
- そのため、同じファイルの中に 新しいメソッド( `eye_catch_display_url` )を追加しても、 既存の `eye_catch_url` の中身や呼び出し結果が変わるわけではない ので、他の画面( 編集画面・管理画面など )には一切影響しない
