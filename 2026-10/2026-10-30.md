## リクエストスペック
```
get    events_path                              # 一覧を取得（GET）
post   events_path, params: { event: { ... } }  # 新しく登録（POST）
patch  event_path(event), params: { ... }       # 更新（PATCH）
delete event_path(event)                        # 削除（DELETE）
```
### have_current_path
