## Reactでトップページを作成（React Router / CSS Modules）

Reactでタスク管理アプリのトップページを作成し、React Routerによるルーティング設定とCSS Modulesによるスタイルの適用を行った。

ディレクトリ構成には、機能ごとにファイルをまとめる**Feature-Based（機能別）**の考え方を採用。

### ① トップページのコンポーネント作成

`src/pages/home/index.tsx`

```
import { Link } from "react-router-dom";

export default function HomePage() {
  return (
    <div>
      <h1>タスク管理アプリ</h1>
      <p>React×Vite×React Routerで作るタスク管理アプリです。</p>
      <Link to="/tasks">タスク一覧へ</Link>
    </div>
  );
}
```

- `HomePage`はトップページを表示するコンポーネント。
- `export default`によって、他のファイルからimportできるようにする。
- `Link`はReact Routerが提供するリンク用コンポーネント。
- `to="/tasks"`で遷移先のURLを指定する。

### ② React Routerによるルーティング設定

`src/App.tsx`

```
import { Route, Routes } from "react-router-dom";
import HomePage from "./pages/home";

function App() {
  return (
    <Routes>
      <Route path="/" element={<HomePage />} />
    </Routes>
  );
}

export default App;
```

- **React Router**は、URLに応じて表示するコンポーネントを切り替えるライブラリ。
- `<Routes>`は、複数のルート設定をまとめる。
- `<Route>`は、URLと表示するコンポーネントを紐づける。
- `path="/"`はトップページのURLを指定する。
- `element={<HomePage />}`は、そのURLで表示するコンポーネントを指定する。

これにより、`/`にアクセスした際に`HomePage`が表示される。

※ React Routerを使用するには、通常アプリの上位で`BrowserRouter`などの設定も必要になる。

### ③ CSS Modulesによるスタイルの適用

`src/styles/home.module.css`

CSS Modulesは、**CSSのクラス名をコンポーネントごとに管理し、他のスタイルとの名前の衝突を防ぐ仕組み。**

```
.title {
  font-size: 2.5rem;
  color: #333;
}
```

`src/pages/home/index.tsx`でimportして使用する。

```
import styles from "../../styles/home.module.css";

<h1 className={styles.title}>タスク管理アプリ</h1>
```

- `.module.css`というファイル名でCSS Modulesとして扱われる。
- `import styles from ...`でCSSのクラスを読み込む。
- `className={styles.title}`でCSSの`.title`を適用する。
- クラス名が内部的に変換されるため、他のコンポーネントとのスタイルの衝突を防げる。

※ JSXではHTMLの`class`ではなく、`className`を使用する。

### まとめ

- **Feature-Based**：機能単位でファイルを整理する設計。
- **React Router**：URLとコンポーネントを紐づけ、SPAの画面遷移を管理する。
- **CSS Modules**：クラス名の衝突を防ぎながら、コンポーネントにスタイルを適用する。

Reactでは、コンポーネントで画面を作成し、React Routerで表示する画面を管理し、CSS Modulesで見た目を整えることができる。
