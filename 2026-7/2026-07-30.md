**:bulb: 理解できたこと**
daisyUIは、Tailwind CSS上で利用できるUIコンポーネントライブラリである。
Tailwind CSSの代わりになるものではなく、btnやcardなどのクラスを追加し、統一感のあるデザインを効率よく実装できる。
また、今回はYarnを使用しているため、次のコマンドで導入した。

docker compose exec web yarn add -D daisyui@latest

-Dを付けることで、CSSを生成するビルド時に使用するパッケージとしてdevDependenciesへ登録される。また、今回使用しているTailwind CSS v4では、従来のtailwind.config.jsではなく、CSSファイルにdaisyUIの設定を書く。
テーマというものがあり、cupcakeなどのテーマを使用する場合は、daisyUIを導入する設定とは別にテーマを有効化し、HTML側で適用するテーマを指定する。
