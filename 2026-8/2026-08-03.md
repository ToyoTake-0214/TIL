**:bulb: 理解できたこと**
`.env`と`/.env*`は、どちらも環境変数を記載したファイルをGitで管理しないために使われます。
目的はほぼ同じですが、無視するファイルの範囲が異なります。
```
.env
```
`.env`という名前のファイルを無視します。
```
/.env*
```
それぞれの記号には、次の意味があります。
* `/` = リポジトリの一番上の階層に限定する
* `.env*` =  `.env`から始まる名前のファイルを対象にする

`.gitignore`には、次の記述もあります。
```
!/.env*.erb
```

先頭の`!`は、無視の対象から除外するという意味
そのため、次のようなテンプレートファイルはGitで管理できる。
```
.env.example.erb
```
