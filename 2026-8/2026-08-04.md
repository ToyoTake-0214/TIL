## ネストしたフォームについて

ネストしたフォームを使うと、親モデルと関連する子モデルのデータを、1つのフォームからまとめて登録・更新できます。

たとえば、`Person`を作成するときに、同じフォーム内で複数の`Address`レコードを登録できます。これにより、自宅や職場などの住所を一度に登録できます。

### モデルの設定

前提として、`Person`モデルと`Address`モデルにアソシエーションを設定します。（has_manyやbelongs_toは設定済みと考え省略)

```
class Person < ApplicationRecord
  accepts_nested_attributes_for :addresses
end
```

`Person`モデルに次の設定を追加します。

```
accepts_nested_attributes_for :addresses
```

この設定によって、`Person`モデルに`addresses_attributes=`という代入用メソッドが作られます。

このメソッドを利用することで、`Person`を保存するときに、関連する`Address`もまとめて作成・更新できます。

### フォームの設定

親モデルのフォーム内で`fields_for`を使うことで、`Person`と`Address`の入力欄を1つのフォームとして扱えます。

```
<%= form_with model: @person do |form| %>
  ~~~
  <%= form.fields_for :addresses do |address_form| %>
    ~~~
  <% end %>
  <%= form.submit %>
<% end %>
```

このように記述すると、`Person`と関連する`Address`の情報を、1つの送信ボタンでまとめて送信できます。

### コントローラーの設定

`new`アクションでは、住所入力欄を表示するために、関連する`Address`の空のインスタンスを用意します。

```
def new
  @person = Person.new
  @person.addresses.build
end
```

`@person.addresses.build`を実行することで、`fields_for :addresses`に対応する住所入力欄が表示されます。

また、Strong Parametersでは、`addresses_attributes`をネストしたパラメータとして許可する必要があります。

```
def person_params
  params.require(:person).permit(
    :name,
    addresses_attributes: [
      :id,
      :kind,
      :street,
      :_destroy
    ]
  )
end
```
これらを設定することで、親モデルと関連モデルを1つのフォームからまとめて登録・更新できるようになります。
