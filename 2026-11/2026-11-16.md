### **正規表現**

正規表現は、文字列の検索・抽出・置換などに使用する。

**基本的な記号**

| 記号          | 意味          |
| ----------- | ----------- |
| `.`         | 任意の1文字      |
| `^` / `$`   | 行頭 / 行末     |
| `\A` / `\z` | 文字列の先頭 / 末尾 |
| `\d`        | 数字          |
| `\w`        | 英数字・`_`     |
| `\s`        | 空白文字        |
| `*` / `+`   | 0回以上 / 1回以上 |
| `?`         | 0回または1回     |
| `[abc]`     | a、b、cのいずれか  |

**よく使うメソッド**

| メソッド    | 役割           |
| ------- | ------------ |
| `match` | 一致した情報を取得    |
| `=~`    | 一致した位置を取得    |
| `scan`  | 一致した部分を配列で取得 |
| `sub`   | 最初の一致を置換     |
| `gsub`  | すべての一致を置換    |
| `split` | 一致部分で分割      |

**実行例**

```
str = "abc123def"

str =~ /\d+/       # 3
str.scan(/\d+/)    # ["123"]
str.gsub(/\d/, "X") # "abcXXXdef"
```

特に `*` と `+`、`sub` と `gsub`、`^` と `\A` の違いを押さえておく。
