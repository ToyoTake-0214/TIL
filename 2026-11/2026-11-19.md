## リファクタリングに向けて
簡単に
具体例：ボタンのクリック
従来のJavaScriptでは、次のようにイベントを登録します。
```
document
  .getElementById("button")
  .addEventListener("click", () => {
    alert("クリックされました");
  });
```

Stimulusでは、HTML側にイベントを宣言します。

```
HTML
<div data-controller="hello">
  <button data-action="click->hello#greet">
    クリック
  </button>
</div>
```
```
// hello_controller.js
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  greet() {
    alert("クリックされました")
  }
}
```

つまり、JavaScript側でDOMを探してイベントを登録する構成から、HTMLとControllerを関連付ける構成に変わる。

既存機能が多い場合、この変更をどこまで適用するかが課題になるので、最初からやっておけばよかったと後悔しています。
