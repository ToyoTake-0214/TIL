## 案外知らなかった配列の引き算


Rubyの配列の引き算で重要なのは、**指定された要素を1つずつ引くのではなく、一致する要素をすべて削除する**

```
a = [1, 2, 3]
b = [1, 3, 5]
c = [2, 3, 4]

p a + b - c
# => [1, 1, 5]
```

### **処理の流れ**

**①&#x20;**`a + b`

```
[1, 2, 3] + [1, 3, 5]
# => [1, 2, 3, 1, 3, 5]
```

`+`は配列を結合します。重複した要素もそのまま残ります。

**②&#x20;**`(a + b) - c`

```
[1, 2, 3, 1, 3, 5] - [2, 3, 4]
# => [1, 1, 5]
```

`c`に含まれる`2`、`3`、`4`をすべて削除します。

特に`3`は2つありますが、**両方とも削除されます。**

### **試験で覚えること**

- `+` → 配列を結合する（重複は残る）
- `-` → 右側の配列に含まれる要素を、左側からすべて削除する
- `-` → 重複した要素もすべて削除する

**配列の引き算は、個数の引き算ではなく、要素の除外処理**と同じ
