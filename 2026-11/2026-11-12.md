## 真の値を返す要素の配列を返すものについて
```
ary = [ 1, 2, 3, 4, 5 ]
p ary.__(1)__ { |i| i.odd? }
[出力]
[1, 3, 5]

どれが入るか
(a) collect
(b) select　←これ
(c) map
(d) filter　←これ
(e) filter_map
```
メソッド 役割 今回の結果
```
collect	各要素を変換	[true, false, true, false, true]
select	条件に合う要素を抽出	[1, 3, 5]
map	各要素を変換	[true, false, true, false, true]
filter	条件に合う要素を抽出	[1, 3, 5]
filter_map	変換結果のうち真と評価される値を集める	[true, true, true]
```
ちなみにodd?はeven?の逆で奇数を返す（割れないやつ）
