#### 補足：単項マイナスと整数リテラルの違い
コメントいただいな内容を調べてみました！
 `-2 ** 2` の解説について、コメントでより厳密な解釈をご教示いただいたので、補足

`-2 ** 2` が `-4` になるのは、べき乗演算子 `**` の優先順位が高いためと説明していましており、これは計算結果を理解するうえでは正しいのですが、厳密には**`-` が整数リテラルの一部なのか、単項演算子なのか**という違いも関係しています。

例えば、以下のコードです。

```
p -2 * 3   # => -6
p -2 ** 3  # => -8
```

一見すると演算子が違うだけですが、実は構文解析の結果も異なります。

- `-2 * 3`：`-2` が負の整数リテラルとして扱われる
- `-2 ** 3`：`2 ** 3` の結果に単項マイナス演算子 `-@` が適用される

この違いは、Rubyの構文解析器である `Prism` を使用すると確認できます。

```
require "prism"

Prism.parse("-2*3")
Prism.parse("-2**3")
```

前者では `-2` が `IntegerNode` として表現されますが、後者では `**` の演算結果に `-@` を適用する構造になります。

つまり、単に演算子の優先順位だけの話ではなく、**そもそも `-` の扱い自体が異なっている**ということです。

これまで実行結果ばかりに注目していたので、構文解析の段階でこのような違いがあることは知りませんでした。
